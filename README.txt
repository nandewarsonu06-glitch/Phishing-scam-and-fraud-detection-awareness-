# CyberSafe – Phishing, Scam & Fraud Detection Awareness Website

A responsive, browser-based awareness website prototype for the B.Sc. IT Community Engagement Project.

## Included
- Home / awareness landing page
- Phishing, smishing, vishing and social-engineering explanations
- Interactive "Spot the Scam" activity
- Safety checklist
- Common scam scenario cards
- 8-question interactive quiz
- CEP community feedback survey
- Local browser storage for survey demo data
- Responsive mobile/desktop design

## How to run
1. Keep `index.html`, `style.css`, and `script.js` in the same folder.
2. Double-click `index.html`, or open it in any modern browser.
3. No internet connection, server or database is required.

## For the CEP presentation
You can demonstrate:
1. Spot the Scam activity.
2. Quiz scoring.
3. Survey collection.
4. Mobile responsiveness.
5. How the website supports community awareness.

The content is based on the supplied University of Mumbai CEP structure and the project topic. Replace/add project-specific field data, photographs, participant counts and observations after your actual community interactions.
